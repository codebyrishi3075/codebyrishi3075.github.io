About Me

I'm a Python and Django Backend Developer based in Kolkata, India, working as the primary backend engineer on a production-deployed healthcare super-app at Famunite Health & Lifestyle Private Limited.

I designed and built a 15-app Django REST Framework backend from schema to deployment — covering doctor consultations, lab testing with multi-provider routing, medicine delivery via 1mg, physiotherapy, eye care, a dual-mode wallet, and a universal payment system across 6 service types.

On the infrastructure side I set up a GitHub Actions CI/CD pipeline with automated Django checks, SSH-based VPS deployment, database migrations, health check verification, and auto-rollback on failure. The server runs on Ubuntu with Nginx, Gunicorn ASGI, and PM2.

I work with Celery + Redis for 16 periodic tasks, Django Channels + WebSockets for real-time vitals streaming, and have integrated 8 third-party services including Razorpay, Agora RTC, Exotel, AWS S3, Firebase FCM, and Twilio.

  • Architected a universal Payment model covering 6 service types (doctor, lab, medicine, physio, eyecare, membership) with a swappable gateway abstraction (Razorpay), HMAC-SHA256 webhook verification, mixed wallet/gateway payment mode, and full refund pipeline with immutable audit ledgers.
  • Built a dual-mode unified wallet system (POINTS_MODE: admin-gifted credits; CASHBACK_MODE: earn-from-bookings percentage cashback) with runtime-configurable parameters via a single-row SystemConfiguration admin model and an append-only WalletTransaction ledger.

  • Engineered 16 Celery periodic tasks covering OTP cleanup, booking TTL expiry, membership lifecycle, cashback unlock on 1mg delivery, stock alerts, abandoned cart reminders, and virtual number bridge release — all non-blocking with retry logic.
  • Implemented real-time vitals streaming (Django Channels + Redis WebSocket layer) so center staff-collected patient vitals (height, weight, BP, SpO2) appear live on the doctor's consultation screen.
  • Set up the full GitHub Actions CI/CD pipeline: Python 3.13 setup, Django system checks, SSH-based VPS deployment, database migrations, PM2 restart, health check verification (15 retries), and automated rollback on failure in under 60 seconds.
  • Applied production security hardening: HSTS (1-year), CORS, CSRF, JWT rotation + blacklist, per-endpoint rate limits (OTP: 5/min), PROTECT constraints on Payment/Refund/WalletTransaction models, and S3 pre-signed URLs with 1-hour expiry.
